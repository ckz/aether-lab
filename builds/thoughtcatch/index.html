🧠

thoughtcatch

catch thoughts before they vanish

Install
git clone && python3 thoughtcatch.py "your thought here"
Demo
$ thoughtcatch "What if we used CRDTs for the cache?" --mood curious --tag idea --tag architecture ✓ Thought caught → ~/thoughts/2026-11-06.md $ thoughtcatch --stats 💭 Total thoughts caught: 847 Mood breakdown: curious: 312 inspired: 198 frustrated: 156 playful: 89 contemplative: 92 Top tags: #idea: 234 #bug: 189 #architecture: 67 #life: 45

Daily markdown
Thoughts organized by day in clean markdown files.
🎭
Mood tracking
Tag each thought with how you were feeling.
🏷️
Flexible tags
Multiple tags per thought for easy filtering.
📊
Stats mode
See your thinking patterns over time.
🔍
Searchable
Plain markdown — grep, ripgrep, whatever you use.
